# Tech Challenge - Fase 1: Case NPS Preditivo 🚀

Este repositório contém o desenvolvimento do **Tech Challenge (Fase 1)** da Pós-Tech FIAP. O objetivo do projeto é analisar dados operacionais de um e-commerce para entender a variabilidade do Net Promoter Score (NPS) e propor uma abordagem preditiva para agir de forma preventiva na experiência do cliente.

---

## 📌 Tópicos do Desafio

O projeto foi estruturado para atender aos quatro pilares do case:

### 1. Entendimento do Negócio
* **Problema:** Alta variabilidade do NPS e falta de previsibilidade antes do encerramento da jornada de compra.
* **Impacto:** Análise de como o NPS afeta a Recompra, o Boca a Boca e o *Market Share*.
* **Aplicações:** Insights para as áreas de Logística, Atendimento, Produto e Estratégia.

### 2. Definição da Target
* **Variável Alvo:** Definição da `nps_score` como métrica central de satisfação.
* **Análise Crítica:** Avaliação do momento de coleta do dado e os riscos de sua utilização inadequada.

### 3. Análise Exploratória dos Dados (EDA)
* **Gargalos:** Identificação dos fatores operacionais que geram clientes detratores.
* **Ponto de Ruptura:** Análise do limite de tolerância do cliente em relação a atrasos e suporte.
* **Foco Gerencial:** Tradução de dados estatísticos em linguagem acessível para decisão.

### 4. Estratégia Preditiva (Desafio Opcional)
* **Abordagem:** Comparativo entre modelos de Regressão e Classificação.
* **Pipeline em Python:** Implementação contendo preparação de variáveis e métricas de avaliação.
